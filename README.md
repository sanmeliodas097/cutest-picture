A Python program that writes one picture to /output/entry.png — a baby seal pup with huge dark eyes and a tiny knitted blue beanie, sitting in soft snow. The picture is shipped as entry.png beside the program, and the program copies it byte-for-byte, so every run is identical with no network access.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
